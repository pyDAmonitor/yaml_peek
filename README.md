# yaml_peek and yaml_peek2
Two convenient online tools to view accessible internet JEDI super YAML files one observer by one observer (`yaml_peek`) or further one filter by one filter for each observer (`yaml_peek2`).   

Usage (applies to both yaml_peek and yaml_peek2):
```
https://wx-workflow.github.io/yaml_peek/yaml_peek2.html?file=URL
```
Replace `URL` with the actual web address.

[Example1](https://wx-workflow.github.io/yaml_peek/yaml_peek2.html?file=https://rapidrefresh.noaa.gov/pyDAmonitor/rrfsv2x/mostrecent/jedivar.yaml):
```
https://wx-workflow.github.io/yaml_peek/yaml_peek2.html?file=https://rapidrefresh.noaa.gov/pyDAmonitor/rrfsv2x/mostrecent/jedivar.yaml
```
**NOTE**: For YAML files in a Github repo, use files' raw URL address instead of its regular github URL.    
[Example2](https://wx-workflow.github.io/yaml_peek2/yaml_peek.html?file=https://raw.githubusercontent.com/NOAA-EMC/rrfs-workflow/refs/heads/rrfs-mpas-jedi/parm/jedivar.yaml):
```
https://wx-workflow.github.io/yaml_peek/yaml_peek2.html?file=https://raw.githubusercontent.com/NOAA-EMC/rrfs-workflow/refs/heads/rrfs-mpas-jedi/parm/jedivar.yaml
```
