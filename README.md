# yaml_peek and yaml_peek2
Two convenient online tools to view accessible internet JEDI super YAML files one observer by one observer (`yaml_peek`) or further one filter by one filter for each observer (`yaml_peek2`).   
## Usage:
```
https://pyDAmonitor.github.io/yaml_peek/yaml_peek.html?file=URL
https://pyDAmonitor.github.io/yaml_peek/yaml_peek2.html?file=URL
```
Replace `URL` with an actual web address.
<br>

## Example1 ([link](https://pyDAmonitor.github.io/yaml_peek/yaml_peek2.html?file=https://rapidrefresh.noaa.gov/pyDAmonitor/rrfsv2x/mostrecent/jedivar.yaml))
```
https://pyDAmonitor.github.io/yaml_peek/yaml_peek2.html?file=https://rapidrefresh.noaa.gov/pyDAmonitor/rrfsv2x/mostrecent/jedivar.yaml
```


## Example2 ([link](https://pyDAmonitor.github.io/yaml_peek/yaml_peek2.html?file=https://raw.githubusercontent.com/NOAA-EMC/rrfs-workflow/refs/heads/rrfs-mpas-jedi/parm/jedivar.yaml))
**NOTE**: For a YAML file in a GitHub repository, obtain the raw URL by opening the file on GitHub and click the `Raw` button in the upper-right corner of the file view. Use the resulting URL (typically from `raw.githubusercontent.com`) instead of the regular `github.com` URL.   
```
https://pyDAmonitor.github.io/yaml_peek/yaml_peek2.html?file=https://raw.githubusercontent.com/NOAA-EMC/rrfs-workflow/refs/heads/rrfs-mpas-jedi/parm/jedivar.yaml
```
