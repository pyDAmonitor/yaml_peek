# yaml_peek
This is a convenient online tool to view accessible internet JEDI super YAML files one observer by one observer.    
Usage:
```
https://wx-workflow.github.io/yaml_peek/yaml_peek.html?file=URL
```
Replace `URL` with the actual web address.

Example:
```
https://wx-workflow.github.io/yaml_peek/yaml_peek.html?file=https://rapidrefresh.noaa.gov/pyDAmonitor/rrfsv2x/mostrecent/jedivar.yaml
```
**NOTE**: For YAML files in a Github repo, use files' raw URL address instead of its regular github URL.    
Eg.
```
https://wx-workflow.github.io/yaml_peek/yaml_peek.html?file=https://raw.githubusercontent.com/NOAA-EMC/rrfs-workflow/refs/heads/rrfs-mpas-jedi/parm/jedivar.yaml
```
